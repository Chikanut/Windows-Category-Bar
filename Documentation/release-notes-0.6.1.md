# Category Bar 0.6.1

Fixes a crash in 0.6.0.

- **Liquid Glass no longer freezes or closes the app.** The live screen capture behind the glass was unstable on Windows 11 and has been removed. The bar, menus and notifications now show the blurred desktop wallpaper behind them, bent at the rim by the same glass shader. This is the same principle as Windows Mica: it is prepared once and costs nothing while the bar is on screen.
- The parameter **Behind the glass** now offers *Blurred wallpaper* or *Transparency only*.
- For theme authors: `backdrop: wallpaper` replaces `backdrop: live` (the old name still works).

If 0.6.0 does not stay open long enough to update, install this version with the setup file from the release page; categories, shortcuts and settings are preserved.

---

Виправляє падіння у 0.6.0.

- **Liquid Glass більше не підвішує й не закриває застосунок.** Живе захоплення екрана за склом виявилося нестабільним на Windows 11, його прибрано. Панель, меню й сповіщення тепер показують розмиті шпалери робочого столу за собою, які на краях заломлює той самий скляний шейдер. Це принцип системної Mica: зображення готується один раз і нічого не коштує, поки панель на екрані.
- Параметр **Фон під склом** тепер пропонує «Розмиті шпалери» або «Лише прозорість».
- Для авторів тем: `backdrop: wallpaper` замінює `backdrop: live` (стара назва працює далі).

Якщо 0.6.0 не тримається відкритою достатньо довго, щоб оновитися, встановіть цю версію файлом Setup зі сторінки релізу; категорії, ярлики й налаштування зберігаються.
