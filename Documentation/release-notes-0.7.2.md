# Category Bar 0.7.2

Fixes the taskbar icon mode over fullscreen games.

- **Menus open when the taskbar is shown over a game.** Pressing the Windows key brings the taskbar up over a fullscreen game without minimising it; hovering a category icon now opens its menu there. While the game covers the taskbar, the place of the icons still opens nothing.

---

Виправляє режим значків на панелі завдань поверх повноекранних ігор.

- **Меню відкриваються, коли панель завдань показано поверх гри.** Клавіша Windows показує панель завдань поверх повноекранної гри, не згортаючи її; наведення на значок категорії тепер відкриває там меню. Поки гра закриває панель завдань, місце значків, як і раніше, нічого не відкриває.
