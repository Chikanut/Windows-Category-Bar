# Перевірка функціональної збірки

Дата: 9 жовтня 2026.

## Виконано

- Release build: 0 помилок, 0 попереджень, warnings-as-errors.
- 26 перевірок моделі: видимість у різних спостережуваних станах, координати, JSON із Unicode й параметрами запуску, п’ять резервних копій, відновлення після пошкодження, валідація, перестановка, undo і rollback при помилці запису.
- Windows Shell виявив 195 програм, зокрема 39 Store-застосунків.
- Створений справжній `.lnk` до системного cmd.exe. Запуск через ShellExecute створив контрольний файл у заданій робочій папці; аргументи й папка відновлені через WScript.Shell.
- Реальні WPF-меню для категорій із 0, 16 і 25 ярликами відкрилися, перейшли в закріплене редагування й закрилися без аварії. Категорія із 25 ярликами використовує сітку.
- Перерахування системних панелей і синхронізація вікон виконані. Це не підтверджує роботу на кількох фізичних моніторах.
- AppBar реально зменшила робочу область на 34 пікселі. Після Dispose робоча область повністю відновилася.
- Self-contained executable скопійований у окрему папку без DLL і пройшов ті самі Windows-перевірки, код виходу 0.
- Раніше виконані перевірки налаштувань: зміна контролів, збереження/reload, видима помилка запису й повторний запис. На цьому етапі повторні рендери налаштувань не запускалися.

Результати локально: `.local/standalone-results/checks.txt`, `.local/standalone-results/catalog.txt`. Повтор: `CategoryBar.exe --self-test <абсолютна тестова папка>`.

## Залишаються інтеграційні перевірки

| Сценарій | Стан |
| --- | --- |
| Системне автоприховування: hidden/revealed і перехід у меню | Не перевірено на справжніх переходах Shell; при приховуванні taskbar меню також закривається |
| Повноекранні ігри/відео та виклик панелі над ними | Модель перевірена, реальна програма не перевірена |
| Перезапуск Explorer | Реалізовані повторне виявлення handle і реєстрація AppBar, реальний restart не виконувався |
| Кілька фізичних моніторів і DPI 125/150/200% | Реалізовано позиціювання за DPI, на різних фізичних моніторах не перевірено |
| Автозапуск після входу в Windows | Реєстрація доступна за кліком; реальний повторний вхід не виконувався |
| Повна відповідність усіх станів дизайну | Основна композиція перенесена; допоміжні діалоги й шрифт відрізняються |

Зелені модельні перевірки не замінюють ці сценарії. Повний статус v1 не заявляється до їх перевірки.
