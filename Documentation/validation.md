# Перевірка версії 0.2

Дата: 9 жовтня 2026. Середовище: Windows 11 Pro 26200, один монітор 1920×1080, масштаб 100 %, темна тема Windows, панель завдань по центру.

## Автоматичні перевірки

`scripts\build.ps1` збирає рішення з warnings-as-errors і запускає 35 перевірок ядра: політика видимості, JSON з Unicode, резервні копії та відновлення, валідація, перестановка, скасування, відкат при помилці запису, класифікатор, межі налаштувань вигляду, завантаження конфігурації попередньої версії.

## Перевірено вручну на запущеному застосунку

Сценарії пройдено мишею на реальному робочому столі з окремою конфігурацією (`scripts\run.ps1 -Fresh`), результат звірено за знімками екрана.

| Дошка: перетягування застосунку між колонками | Працює, з лінією місця вставки |

## Не перевірено

Ці сценарії реалізовані, але в цій версії не запускалися:

| Сценарій | Примітка |
| --- | --- |
| Автоприховування панелі завдань | Панель іде за панеллю завдань і лишається, поки курсор у меню; на справжніх переходах не перевірено |
| Повноекранні ігри та відео | Логіка видимості покрита модельними перевірками, справжній застосунок не запускався |
| Перезапуск Explorer | Основна панель щотакту шукає `Shell_TrayWnd` заново, значок у треї реєструється повторно; перезапуск не виконувався |
| Кілька моніторів, різний DPI | Вторинні панелі створюються для кожної `Shell_SecondaryTrayWnd`; фізично не перевірено |
| Резервування місця на екрані | Код AppBar перенесено з попередньої версії без змін у логіці; повторно не перевірявся |
| Меню в треї, виправлення зламаного ярлика, запуск від імені адміністратора | Не запускалися |
| Перейменування ярлика в меню, режим редагування меню, перетягування вкладок | Не запускалися |
| Перетягування файлів із Провідника | Не запускалося |
| Автозапуск після входу в Windows | Запис у `HKCU\…\Run` створюється; повторний вхід не виконувався |

## Відоме

- Під час першого відкриття меню після запуску позначки запущених застосунків іноді з’являються приблизно на секунду пізніше за рядки.
- Windows 11 не дає програмно відкріпити значки з панелі завдань.
