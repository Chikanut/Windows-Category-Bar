# Значки категорій на панелі завдань Windows

Режим вмикається на останньому кроці майстра першого запуску, в Налаштування → «Панель і меню» → «Значки на панелі завдань» або в меню трею. Панель категорій ховається, а кожна категорія стає значком на панелі завдань Windows: наведення або клацання відкриває меню категорії, права кнопка показує її застосунки (Jump List).

## Як це влаштовано

1. **Ярлик на категорію.** У `TaskbarGroups` поруч із конфігурацією створюється `.lnk`, що запускає `CategoryBar.exe --category <id>` і має власний AppUserModelID, тому Windows вважає кожну категорію окремим застосунком. Другий процес лише передає запит працюючому через іменований канал.
2. **Значок.** Це `.ico` в `TaskbarGroups\Icons`: іконка застосунку категорії, символ із системного шрифту Segoe Fluent Icons на кольоровій плитці або до трьох літер на плитці акцентного кольору теми. Коли застосунок категорії запущено, значок перемальовується із зеленою крапкою. Назва файлу містить хеш вигляду, тому кеш іконок Windows не повертає старе зображення.
3. **Закріплення.** Windows не дає застосункам API для закріплення ярлика. Список закріплених Explorer зберігає в `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Taskband` (`Favorites`, `FavoritesResolve`, `FavoritesChanges`), а копії ярликів — у `%APPDATA%\Microsoft\Internet Explorer\Quick Launch\User Pinned\TaskBar`. Програма копіює ярлик у цю папку, додає запис у список і просить панель перечитати його (повідомлення `0x446` вікну `MSTaskSwWClass`). Права адміністратора й перезапуск Explorer не потрібні.
4. **Порядок.** Значки категорій стоять першими на панелі завдань. Нові додаються в кінець групи, а порядок, який користувач задав перетягуванням, зберігається. Чужі закріплені значки зберігають свій порядок. Панель ставить новий закріплений значок правіше вже запущених програм, тому після закріплення кнопки таких програм переносяться в кінець панелі (`ITaskbarList::DeleteTab` + `AddTab` для всіх вікон кнопки разом).
5. **Роздільник.** Після значків категорій закріплюється тонка риска — ярлик `CategoryBar.exe --divider`, який нічого не робить. Вимикається в налаштуваннях.
6. **Вимкнення режиму.** Записи й копії ярликів категорій видаляються, панель категорій повертається.

## Межі

- Формат списку закріплених не документований. Його взято із записів, які Explorer створює сам (Windows 11, збірка 26200). Список, який не вдається розібрати, програма не чіпає; якщо Explorer відхилить запис, з’явиться підказка закріпити ярлики вручну з папки.
- Кнопку запущеної програми, яку не вдалося зіставити з її вікнами, програма не переносить; вона стане на місце після перезапуску цієї програми.
- Значок, відкріплений користувачем вручну, не закріплюється знову, доки не натиснути «Закріпити всі».
- Після перейменування категорії підказка значка зберігає стару назву до повторного закріплення.
- Після видалення програми значки категорій треба відкріпити вручну.
