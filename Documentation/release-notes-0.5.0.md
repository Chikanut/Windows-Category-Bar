# Category Bar 0.5.0

- Drag a shortcut onto the miniature-mode arrow to reveal the category bar. Keep dragging onto the target category to add it; the bar stays open during the drag.
- New theme system: independent layouts, component styles, animations, shader materials and settings for each theme.
- Import and export themes, including custom styles and shader assets.
- Existing settings, categories and shortcuts are preserved; update from 0.4.0 using **Settings → General → Update and restart**.
- Saving settings tolerates brief Windows file-sharing locks while retaining atomic replacement.

New installation: download `CategoryBar-win-Setup.exe`. Installed 0.4.0 users can click **Check for updates**, then **Update and restart**.

---

- Перетягніть ярлик на стрілку мініатюрного режиму — панель розкриється. Продовжуйте перетягування до потрібної категорії, щоб додати ярлик.
- Нова система тем: окремі макети, стилі компонентів, анімації, шейдерні матеріали й налаштування для кожної теми.
- Імпорт та експорт тем, зокрема власних стилів і шейдерів.
- Наявні категорії, ярлики й налаштування зберігаються.
- Збереження налаштувань витримує короткочасне блокування файла у Windows.

Для оновлення з 0.4.0 відкрийте **Налаштування → Загальне → Перевірити оновлення**, потім натисніть **Оновити та перезапустити**.
