# Перенесення з панелі завдань Windows

Майстер першого запуску (і Налаштування → Загальне → «Відкрити майстер») читає закріплені застосунки й пропонує їх розподіл по категоріях. До натискання «Готово» нічого не зберігається; розподіл можна поправити на дошці.

## Звідки беруться застосунки

1. **Закріплені ярлики.** Класичні програми мають `.lnk` у `%APPDATA%\Microsoft\Internet Explorer\Quick Launch\User Pinned\TaskBar`.
2. **Кнопки панелі завдань.** Застосунки з Microsoft Store не мають такого ярлика, тому кнопки читаються через UI Automation. Ідентифікатор кнопки містить AppUserModelID (`Appid: …`), за ним застосунок знаходиться в `shell:AppsFolder`. Порядок кнопок задає порядок імпорту.

Панель показує і закріплені, і просто запущені програми. Закріплену не запущену програму Windows називає «<назва><суфікс>» (в англійській Windows — `Signal pinned`). Суфікс визначається з кнопки, для якої закріплений ярлик точно існує, і далі використовується для Store-застосунків, тому перевірка не залежить від мови системи. Якщо суфікс визначити не вдалося, беруться Store-застосунки без кількості відкритих вікон у назві.

Межі: це не експорт внутрішнього формату Taskband. Store-застосунок, якого немає в `shell:AppsFolder`, і кнопки, недоступні для UI Automation, не потраплять до списку. Перевірено на Windows 11 (26200) з англійською мовою інтерфейсу: 15 із 15 закріплених застосунків, зокрема три зі Store.

## Розподіл по категоріях

Категорію пропонує `ApplicationClassifier` за назвою, шляхом і описом EXE: «Розробка», «Браузери», «Спілкування», «Медіа», «Ігри», «Робота», «Системні». Невпізнані застосунки потрапляють у «Програми». Це евристика, тому другий крок майстра — перевірка на дошці.

Якщо категорії вже є, імпорт їх не чіпає: додаються лише застосунки, яких на панелі ще немає, у категорію з відповідною назвою або в нову.

## Що відбувається з ярликами

Закріплені `.lnk` копіюються в `ImportedShortcuts` поруч із конфігурацією, тому відкріплення оригіналу не ламає ярлик на панелі. Власна іконка, аргументи й робоча папка ярлика зберігаються.

## Відкріплення в Windows

Windows 11 не дає стороннім програмам відкріплювати значки: команда оболонки `taskbarunpin` більше не діє. Програма не змінює двійкові значення реєстру Taskband і не перезапускає Explorer. Після перенесення значки відкріплюються вручну: права кнопка → «Відкріпити від панелі завдань». Про це нагадує повідомлення наприкінці майстра.

Довідка Windows: [налаштування панелі завдань](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows).
