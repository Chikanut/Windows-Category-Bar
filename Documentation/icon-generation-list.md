# Іконки для «Панелі категорій»

> Стан на версію 0.2: іконка застосунку векторна — `src/CategoryBar/Assets/App.svg`. Скрипт `scripts/make-icon.ps1` растеризує її та збирає `App.ico` з розмірами 16–256 px; ця ж іконка використовується в треї. Щоб змінити іконку, відредагуйте SVG і запустіть скрипт. Окремі `Tray.ico` і `Brand.png` зараз не використовуються.

Потрібні **три зображення одного символу**. Іконки встановлених програм беремо з Windows — генерувати їх не потрібно.

| Зображення | Де використовується | Що підготувати |
| --- | --- | --- |
| Основна іконка | EXE, ярлик запуску, меню Пуск, заголовки вікон | PNG 1024×1024 з прозорим фоном; ICO з розмірами 16, 20, 24, 32, 40, 48, 64, 128, 256 px |
| Спрощений символ | Системний трей (біля годинника), мала бічна панель | PNG 256×256, прозорий фон; чіткий силует для 16–32 px; ICO 16, 20, 24, 32, 40, 48 px |
| Символ запуску / бренду | Майбутній екран запуску, сторінка «Про програму» | PNG 512×512 і 1024×1024 з прозорим фоном, без написів |

Для значка трея підготувати світлий і темний варіант: світлий знак для темної панелі Windows, темний — для світлої. Дрібні деталі та текст на 16 px не читатимуться.

## Узгоджений образ

Символ: три компактні плитки застосунків, зібрані в одну панель або папку категорії. Заокруглені кути, прості геометричні форми, акцент #8EA8FF. Основна іконка може мати м’який об’єм; трей — плоский силует. Залишити 10–15% прозорого поля, без фону та дрібного тексту.

### Промпт основної іконки

«Створи сучасну іконку Windows-застосунку “Панель категорій”: три впорядковані плитки програм над компактною горизонтальною панеллю, символ організації застосунків у категорії. Прості виразні геометричні форми, заокруглені кути, акцентний перивінкль #8EA8FF, делікатний об’єм. Центрована квадратна композиція, прозорий фон, без літер, написів, водяних знаків і макета екрана. Чітка впізнаваність у малому розмірі. 1024×1024.»

### Промпт іконки трея

«Спрости надану іконку до одноколірного геометричного символу для системного трея Windows: три плитки й панель, товсті чіткі форми, мінімум деталей. Без градієнтів і тіней. Прозорий фон. Варіант білим і окремий варіант темним #20202A. Символ має читатися при 16×16 пікселях. 256×256.»

### Промпт символу запуску

«Використай той самий символ трьох плиток і панелі, створивши більший чистий бренд-знак для екрана запуску та сторінки “Про програму”. Акцент #8EA8FF, прозорий фон, без тексту й оточення. Стиль та пропорції основної іконки зберегти. 1024×1024.»

## Файли для інтеграції

- `src/CategoryBar/Assets/App.ico` — основна іконка; збірка підхоплює її автоматично, коли файл наявний.
- `src/CategoryBar/Assets/Tray.ico` — спрощений значок трея, за відсутності використовується значок EXE.
- `src/CategoryBar/Assets/Brand.png` — знак для сторінки «Про програму» та майбутнього екрана запуску.

PNG потрібно експортувати в ICO з переліченими розмірами після генерації. Окремий екран запуску зараз не потрібний: панель запускається без заставки.
