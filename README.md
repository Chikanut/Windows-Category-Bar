# Панель категорій для Windows 11

Вкладки категорій над панеллю завдань Windows. Наведіть курсор на вкладку — її застосунки відкриються колонкою. Панель з’являється і зникає разом із панеллю завдань. Вигляд і поведінка взяті з `Design/Панель категорій.dc.html`.

## Запуск

Відкрийте `artifacts/portable/CategoryBar.exe`. Це самодостатній Windows x64 executable, встановлювати .NET не потрібно.

Під час першого запуску відкривається майстер із трьох кроків:

1. **Спосіб.** Перенести закріплені застосунки з панелі завдань Windows, почати з готових порожніх категорій або з порожньої панелі. Якщо категорії вже є, перший варіант — залишити їх.
2. **Категорії.** Дошка з колонками: застосунки перетягуються між категоріями, категорії — за заголовок. Тут же перейменування, видалення й додавання.
3. **Вигляд.** Тема, колір акценту, автозапуск.

Нічого не зберігається, доки ви не натиснете «Готово». Майстер можна відкрити знову: Налаштування → Загальне.

Налаштування й вихід — через значок у системному треї або правою кнопкою по панелі.

Дані: `%LOCALAPPDATA%/WindowsCategoryBar/config.json`. Збереження атомарне, з п’ятьма резервними копіями й відновленням після пошкодження. Для окремої конфігурації: `CategoryBar.exe --config <шлях>`.

## Можливості

**Панель і меню**
- Меню відкривається при наведенні із затримкою, клік відкриває й закриває одразу, Esc закриває.
- Перетягування вкладки змінює порядок категорій, подвійний клік перейменовує на місці.
- Перетягування ярлика в меню змінює порядок; над іншою вкладкою ярлик переходить у ту категорію.
- Файли з Провідника (`.exe`, `.lnk`, `.url`, папки) можна кинути на вкладку або в меню.
- Пошук у великих категоріях, сітка від 20 ярликів, зайві вкладки ховаються в «Ще N».
- Режим редагування меню, контекстні меню ярлика й категорії, властивості ярлика, видалення з перенесенням ярликів.
- Кожна зміна має «Скасувати» в повідомленні.

**Статуси застосунків**
- Запущений застосунок має позначку під іконкою, категорія із запущеними — під назвою.
- Клік по запущеному застосунку переходить до його вікна; Shift + клік відкриває нове вікно, Ctrl + Shift + клік запускає від імені адміністратора.
- Ярлик без файлу позначено попередженням; клік пропонує вказати новий файл або прибрати ярлик.
- Під час запуску показується індикатор, для ярликів «від адміністратора» — щит.

**Вигляд**
- Тема: як у Windows, темна або світла. Режим «як у Windows» перемикається разом із системою.
- Акцент: колір Windows або власний (набір готових чи `#RRGGBB`), за бажання — тонування поверхонь.
- Шрифт, масштаб 80–150 %, непрозорість, заокруглення кутів. Усе застосовується одразу.

**Розташування**
- Вирівнювання як у Windows, ліворуч, по центру або праворуч; основний чи всі монітори; поверх вікон або з резервуванням місця.
- Мініатюрний режим (Налаштування → Панель і меню): панель ховається за панель завдань, над нею видно лише стрілку; при наведенні панель виїжджає, після виходу курсора ховається назад.

Як працює перенесення з панелі завдань: [Documentation/taskbar-import.md](Documentation/taskbar-import.md).

## Стек і збірка

C# / .NET 10, WPF, Win32 / DWM / Windows Shell, System.Text.Json. Сторонніх NuGet-пакетів немає. Для розробки потрібен SDK 10.0.4xx.

```powershell
.\scripts\build.ps1 -SelfContained   # збірка, перевірки ядра, executable в artifacts\portable
.\scripts\run.ps1 -LocalConfig       # збірка й запуск з окремою конфігурацією .local\dev
.\scripts\run.ps1 -Fresh             # те саме з чистою конфігурацією — знову покаже майстер
```

Іконка застосунку векторна: `src/CategoryBar/Assets/App.svg`. Після правок `.\scripts\make-icon.ps1` збирає з неї `App.ico` (для растеризації потрібен Edge або Chrome).

Будова коду:

| Шлях | Зміст |
| --- | --- |
| `src/CategoryBar.Core` | Модель, збереження, скасування, політика видимості, класифікатор |
| `src/CategoryBar/Session.cs` | Стан застосунку: зміни, скасування, повідомлення, запуск |
| `src/CategoryBar/Theme.cs`, `Themes/Controls.xaml` | Тема як динамічні ресурси та стилі елементів |
| `src/CategoryBar/Services` | Іконки, ярлики, каталог програм, статуси — усе поза потоком інтерфейсу |
| `src/CategoryBar/Views` | Панель, меню, повідомлення, налаштування, майстер, дошка категорій |
| `src/CategoryBar/Interop` | Win32 і резервування місця на екрані |

## Перевірки та межі

Перевірене й неперевірене: [Documentation/validation.md](Documentation/validation.md). Коротко: основні сценарії перевірено на Windows 11 з одним монітором 1920×1080 при 100 %; кілька моніторів, автоприховування панелі завдань, повноекранні ігри та резервування місця в цій версії вручну не перевірялися.

Windows 11 не дає програмно відкріпити значки з панелі завдань, тому після перенесення їх потрібно відкріпити вручну.
