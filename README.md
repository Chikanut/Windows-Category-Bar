# Панель категорій для Windows 11

Нативна панель запуску над стандартною панеллю Windows. Проєкт розпочато на основі [специфікації](Documentation/windows-category-bar-project.md) і [дизайну](Design/Панель%20категорій.dc.html).

**Статус: технічний прототип, не готова v1.** Ключовий наступний крок — перевірити фактичну видимість із автоприховуванням і повноекранними програмами до повного перенесення дизайну.

## Стек

| Частина | Технологія | Призначення |
| --- | --- | --- |
| Мова / runtime | C#, .NET 10 LTS | Нативний Windows-застосунок |
| Інтерфейс | WPF, XAML, Segoe UI | Власні панель, меню та діалоги |
| Windows Shell | Win32 P/Invoke, DWM, ShellExecute | Положення, DPI, стан Explorer, запуск оригінальних ярликів |
| Трей | Windows Forms NotifyIcon | Налаштування, приховування та вихід |
| Конфігурація | System.Text.Json | Локальний файл, атомарна заміна, 5 резервних копій |
| Перевірки | Консольний runner без сторонніх пакетів | Правила видимості й відновлення даних |
| Збірка | dotnet SDK, PowerShell, Git | Локальна розробка та portable-вивід |

Потрібні .NET SDK 10.0.401 для розробки або .NET Desktop Runtime 10 для поточної portable-збірки. Зовнішніх NuGet-залежностей немає. Self-contained-пакування заплановане окремо.

## Збірка й запуск

```powershell
.\scripts\build.ps1 -Publish
.\scripts\run.ps1 -LocalConfig
```

`-LocalConfig` зберігає дані всередині `.local/app` у репозиторії. Без параметра конфігурація зберігається у `%LOCALAPPDATA%/WindowsCategoryBar/config.json`.

Portable-вивід: `artifacts/portable/CategoryBar.exe`. Потрібно зберігати всю папку разом із DLL і файлами runtimeconfig/deps.

На першому запуску панель порожня: «Створити першу категорію». Додайте програму через меню категорії або перетягніть `.exe`, `.lnk`, `.url` чи папку з Провідника. Наведення відкриває меню; клік запускає програму. ПКМ дає перейменування, перестановку та видалення посилань. Налаштування й вихід доступні також у треї.

Для діагностики реальної панелі Windows:

```powershell
.\src\CategoryBar\bin\Release\net10.0-windows\CategoryBar.exe --probe .\taskbar-observation.json
```

Передавайте абсолютний шлях, якщо запускаєте команду з іншої папки. Режим `--smoke --config <абсолютний-шлях>` запускає прототип і завершує його через 3 секунди. Журнал змін спостережуваного стану: `taskbar.log` поруч із конфігурацією, до 1 MB плюс один попередній журнал.

## Межі прототипу

Основний монітор, нижня панель Windows, перекриття вікон. Правила видимості використовують геометрію, IsWindowVisible, DWM cloaking, повноекранне foreground-вікно та фактичний z-order. Опитування кожні 100 мс може давати затримку й потребує перевірки на реальних сценаріях Windows 11. Це евристика, а не підтверджена гарантія синхронізації.

Якщо Windows приховує власну панель під час переходу до меню, прототип закриває меню разом із нею. Утримання системної панелі видимою ще не реалізовано. Перевірка DPI на кількох моніторах також не завершена.

Поки відсутні: AppBar-резерв місця, панель на всіх моніторах, прямий вибір Store-застосунків, сканування меню «Пуск», inline-редагування, drag reorder, undo, власні тости, сітка, властивості ярликів та автозапуск. Налаштування й діалоги прототипу спрощені відносно дизайн-доку.

Деталі: [рішення й відповідність дизайну](Documentation/implementation-plan.md), [матриця перевірки інтеграції](Documentation/validation.md).
