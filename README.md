# Панель категорій для Windows 11

Нативна панель запуску над панеллю Windows, створена за специфікацією та Design/Design.pdf. Поточна збірка — функціональна версія для локального використання й перевірки інтеграції з Windows.

## Запуск

Відкрийте `artifacts/portable/CategoryBar.exe`. Це самодостатній Windows x64 executable: встановлювати .NET не потрібно, можна копіювати лише цей файл. Перший запуск пропонує створити категорію. Налаштування та вихід доступні через ⚙ і системний трей.

Дані: `%LOCALAPPDATA%/WindowsCategoryBar/config.json`. Збереження атомарне, підтримуються п’ять резервних копій і відновлення після пошкодження. Для ізольованої конфігурації: `CategoryBar.exe --config <абсолютний шлях>`.

## Можливості

- Створення, inline-перейменування, видалення категорій із перенесенням ярликів та перестановка перетягуванням.
- Вибір програм із меню «Пуск» і Microsoft Store; додавання `.exe`, `.lnk`, `.url`, папок, вебпосилань і Steam URL.
- Пошук у категорії, прокручування, опційна сітка від 20 ярликів, приховані вкладки в меню «Ще».
- Запуск оригінальних ярликів; аргументи, робоча папка, запуск адміністратором, властивості й виправлення відсутнього файлу.
- Закріплене редагування, перестановка ярликів перетягуванням, перенесення між категоріями, видалення зі скасуванням.
- Власні повідомлення зі скасуванням останньої зміни; системні повідомлення, коли панель прихована.
- Панель на основному або всіх моніторах із панеллю Windows; вирівнювання, затримки, лічильники, пошук, перекриття або резервування місця.
- Автозапуск через налаштування, системний трей, приховування й вихід.

## Стек і збірка

C# / .NET 10, WPF / XAML, Win32 / DWM / Windows Shell, Windows Forms NotifyIcon, System.Text.Json. Сторонніх NuGet-пакетів немає. Для розробки потрібен SDK 10.0.401.

```powershell
.\scripts\build.ps1 -SelfContained
.\scripts\run.ps1 -LocalConfig
```

`-Publish` готує framework-dependent варіант, `-SelfContained` — самодостатній executable. `-VisualCheck` — окрема перевірка сторінок налаштувань.

## Перевірки та межі

Release-збірка: 0 помилок і попереджень. 26 автоматичних перевірок моделі та збереження. Додатковий Windows-тест перевіряє каталог встановлених програм, реальний запуск `.lnk` з аргументами й робочою папкою, меню для 0/16/25 ярликів, синхронізацію моніторів і резервування/звільнення робочої області.

```powershell
.\artifacts\portable\CategoryBar.exe --self-test <абсолютна тестова папка>
```

Цей тест короткочасно відкриває власні тестові вікна, створює тестовий ярлик до cmd.exe та відновлює зарезервовану область. Конфігурація користувача й автозапуск не змінюються.

Фактичні переходи автоприховування, повноекранні ігри, перезапуск Explorer та різний DPI на кількох фізичних моніторах ще не підтверджені. Політика видимості читає геометрію taskbar, DWM cloaking, foreground і z-order кожні 100 мс. Якщо системна панель ховається, меню закривається разом із нею; утримання автоприхованої панелі під час переходу до меню потребує перевірки.

Композиція, базові розміри й кольори взяті з дизайну. Абсолютна піксельна відповідність усіх діалогів ще не підтверджена: допоміжні діалоги використовують стандартну рамку Windows, шрифт — Segoe UI.

Деталі перевірок: `Documentation/validation.md`.
